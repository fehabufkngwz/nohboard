## 🕹️ Overview

NohBoard renders your keyboard and mouse inputs in real time on screen, helping viewers follow your inputs. Fully skinnable with community-made themes.

Whether you're a newcomer or a veteran, NohBoard provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Key Visualization** | Real-time display of all keyboard key presses and releases |
| **Mouse Tracking** | Shows mouse button clicks and optionally cursor position |
| **Custom Skins** | Import community skins or design your own with the built-in editor |
| **Capslock Aware** | Correctly reflects modifier and toggle key states |
